# BIEN MANGER（ヴィアン マンジェ）ホームページ リニューアル案

京都・丸太町のフランス料理店 BIEN MANGER（https://bien-manger.jp/）向けのリニューアル提案デモです。
Cloudflare Workers（静的アセット＋API）だけで動きます。

## 構成

```
public/            静的サイト（日本語 / en/＝英語版 / assets/ / menu-editor/＝店内メニュー編集ツール）
src/index.js       Worker：/api/instagram（最新投稿）、/api/event（クリック計測）、Cron
wrangler.jsonc     Cloudflare 設定
```

### ページ構成（内容が重ならないように役割を分けています）

| ページ | 伝えること | 主な内容 |
|---|---|---|
| `/` トップ | お店の世界観 | 写真カルーセル、コンセプト（店主の言葉・土壁の写真）、各ページへの入口、Instagram |
| `/cuisine/` 料理とワイン | 何を食べられるか・いくらか | 銘柄和牛ステーキ、魚と前菜、かまど炊きのご飯、コースの流れ、コースと料金の一例、ワイン、ワインセレクションパートナー 深山由佳氏（写真・経歴・メッセージ） |
| `/space/` 空間と職人 | どんな場所か | 土壁とかまど（蒼築舎）、檜カウンター（BROOK）、椅子（AJIM・川端装飾）、お席（カウンター・テーブル）、しつらえ |
| `/chef/` シェフ | 誰がつくるか | 中西潤也シェフの想い、経歴、店名の意味 |
| `/guide/` ご来店案内 | どう行くか・何に気をつけるか | 予約方法、営業時間、定休日、服装、アレルギー、お子様、禁煙、キャンセル、支払い、アクセス |

全ページ共通の「ご予約」欄：TableCheck（メイン）／一休／食べログ／電話。英語版は `/en/` 以下に同じ構成です。

- **Instagram 連携**：Cron（30分ごと）で Instagram API から最新12件を取得して KV に保存。ページは `/api/instagram` を読むので、新しい投稿が自動で反映されます。長期トークン（60日）は7日ごとに自動延長。
- **トークン未設定時**はデモ用の投稿（固定投稿3本の構成案を含む）を表示します。提案時はこの状態で見せられます。
- **計測**：予約・電話・地図・Instagram のクリックを Workers Analytics Engine（`bien_manger_events`）に記録。ダッシュボードで Analytics Engine を有効化し、`wrangler.jsonc` のコメントを外すと動きます（未設定時は計測をスキップ）。予約完了数は TableCheck 側の数字と照合してください。

## デモ公開（Cloudflare）

```sh
npm install
npx wrangler login
npx wrangler deploy        # → https://bien-manger-demo.<account>.workers.dev
```

GitHub 連携で自動デプロイする場合は、Cloudflare ダッシュボード → Workers & Pages → Create → Import a repository でこのリポジトリを選択。

## Instagram を本番接続する

1. Instagram アカウントをプロアカウント（ビジネス／クリエイター）に切り替え
2. Meta for Developers でアプリを作成し「Instagram API with Instagram login」を追加、長期アクセストークンを発行
3. KV（`bien-manger-demo-IG_KV`）とユーザー名 `bien_manger_kyoto` は設定済み
4. トークンをシークレットとして登録してデプロイ
   ```sh
   npx wrangler secret put IG_ACCESS_TOKEN
   npx wrangler deploy
   ```

## 店内メニュー編集ツール（`/menu-editor/`）

店内で使う印刷用メニューを、ブラウザだけで作成・編集するスタッフ向けツールです（公開ページからはリンクしておらず、検索エンジンにも載せません）。
`https://<公開URL>/menu-editor/` を開いて使います。ローカルで試すときは `npx wrangler dev` → `http://localhost:8787/menu-editor/`。

- **端末内だけで動作**：ログイン・クラウド共有なし。メニューと取り込んだ写真はブラウザ内（IndexedDB）に保存し、外部へ送信しません（読み込むのはフォントだけ）。
- **画面構成**：左「料理・素材・ページ・レイヤー」／中央「編集・プレビュー（A4）」／右「選択した要素の設定」。
- **料理情報**：料理名・説明・価格（「時価」など文字も可）・写真・カテゴリー・補足表示（おすすめ・季節限定など）。追加・削除・複製・並べ替え、写真の表示／非表示。
- **料理リスト**：登録した料理を決まった書式で並べる枠。収まらないときは知らせ、「次のページへ続ける」で続きのリストを作成（文字は自動で小さくしません）。
- **紐付け**：文字や写真枠を料理の「料理名・説明・価格・写真」に紐付けると、料理情報の変更がデザインに反映されます。
- **画像**：JPEG・PNG・WebP（透過PNG対応）。デザイン素材は自由配置・拡大縮小・回転・透明度・重なり順・背景に設定・ロック。写真枠は四角／角丸／丸、「枠いっぱいに切り抜く／画像全体を収める」、トリミング（拡大・表示位置）。差し替えても枠はそのまま。印刷に対して解像度が足りない画像は注意を表示（150dpi未満）。
- **既存メニューの取り込み**：画像・PDF（ページを選択）を取り込み、「下敷きにして作り直す」（半透明表示・印刷されない）か「背景として使う」（ロック、上に文字や隠し用の図形を置く）を選べます。文字認識・自動分解は今後の追加機能の候補です。
- **テンプレート**：写真なしのシンプル／料理写真付き／季節のおすすめ1枚／白紙。保存済みメニューは一覧から複製して別名で管理できます。
- **保存**：自動保存。「バックアップ」で画像を含む編集データ一式を1つのファイル（`.menu-backup.json`）に書き出し、別のブラウザ・パソコンで読み込めます。
- **印刷・PDF**：編集用の枠やボタンを除いてメニューだけを印刷。用紙サイズ・改ページを反映し、画像とフォントの読み込みを待ってから印刷します。印刷画面で「PDFに保存」を選ぶと PDF になります（余白「なし」、倍率100%推奨）。

```
public/menu-editor/
  index.html, editor.css
  js/app.js        起動・メニュー一覧・ツールバー・キーボード操作
  js/render.js     メニューの描画（編集画面と印刷で共通）・はみ出し／印刷範囲／解像度のチェック
  js/canvas.js     選択・移動・拡大縮小・回転・トリミング・整列ガイド・ドロップ
  js/ui-*.js       左右のパネル（料理・素材・ページ／レイヤー・設定）
  js/store.js      状態・元に戻す／やり直し・自動保存
  js/importer.js   既存メニュー（画像・PDF）の取り込み
  js/backup.js     バックアップの書き出し・読み込み
  vendor/pdfjs/    PDF の読み込み（pdf.js legacy build、Apache-2.0）
```

## 写真

`public/assets/photos/` の WebP を使っています（元の写真は Google ドライブの共有フォルダに「番号_内容_ファイル名」で整理）。
トップのコンセプト欄の土壁の写真（`earthwall-branches*.webp`）は現在の公式サイトのメイン画像です。
カルーセルに足したい場合は `index.html` の `hero-slide` を1行追加します。Instagram 連携後は、最新投稿の写真3枚もカルーセルに自動で追加されます。
